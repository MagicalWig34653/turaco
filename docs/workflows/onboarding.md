# Employee Onboarding

## Goal
Coordinate equipment/access/workplace preparation for a new employee using existing primitives.

## Flow
1. Authoritative organization/HR/AD signal or manual process creates/identifies User and start-date context.
2. Onboarding workflow creates Tasks, Service Requests/Product Requirements and Access Requests based on role/location/template.
3. Inventory reservations and Procurement happen through normal domains.
4. Endpoint provisioning and physical workplace setup are Tasks/Deployments.
5. Asset assignments happen at handover.
6. Outstanding mandatory work is visible in My Work and onboarding status.
7. Completion records the delivered set; no separate "onboarding asset database" exists.
