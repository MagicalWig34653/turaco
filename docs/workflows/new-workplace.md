# New Workplace

## Goal
Fulfill a bundle of products, access and setup work as one user request.

## Flow
1. `New Workplace` Catalog Item captures only context not already known (start date, workplace/site/requirements).
2. Request workflow expands into required Product Requirements and Tasks (not separate unrelated requests unless organizationally required).
3. Approval occurs once or per configured high-cost item.
4. Inventory reserves notebook/dock/monitors/peripherals independently; missing components create Procurement Requests.
5. Tasks cover provisioning, physical setup and handover.
6. Asset assignments are created at issue/handover, not at reservation time.
7. Request completes only when mandatory components/tasks are satisfied; optional components may be explicitly waived.

The bundle reuses Product, Reservation, Task, Procurement, Asset Assignment and Notification concepts.
