# ADR-0017: Turaco Project Name

**Status:** Accepted for project use; public brand clearance pending

## Decision

Use **Turaco** as the repository and product working name.

Brand-specific names may be used for executables, container images and UI identity. Domain terminology and database concepts remain business-oriented rather than brand-prefixed.

## Consequences

- Binaries use names such as `turaco-api`, `turaco-worker` and `turaco-migrate`.
- The frontend package is `turaco-web`.
- Public launch is blocked on formal name/trademark clearance documented in `docs/product/name-clearance.md`.
