# Backend Domain Modules

Only implemented modules receive code directories. Do not create empty package trees merely to mirror the roadmap.

Current foundation packages:

- `organization` — canonical users/teams/locations foundation.
- `products` — shared product catalog foundation for catalog/inventory/procurement/assets.
- `tasks` — shared operational work foundation.

Planned ownership boundaries are authoritative in `docs/architecture/module-boundaries.md`. When a planned domain receives its first real behavior, create it using `docs/development/module-template.md` and the `/feature-design` Claude skill.
