02 / BUILT WITH INTENTION

Good foundations.
Fewer surprises.

A connected workspace needs more than connected screens. These are the rules shaping the system underneath.

01

Open-source-first

A useful self-hosted product is the direction. Source is public; the distribution license still awaits legal review.

02

One modular monolith

Explicit domains, public contracts and shared platform services. Complexity belongs in the problem, not the plumbing.

03

Trust is explicit

Backend authorization, least privilege and audit records for important changes. Agents are restricted trust boundaries.

04

Evidence keeps its origin

External observations preserve source and freshness. Unknown stays unknown; stale data never becomes certainty.

04 / THE ROAD AHEAD

Built in slices.
Shared in the open.

12 phases, one connected direction. Status reflects the documented build, not a release commitment. F9–F12 sequencing remains open.

Done: core scope with documented gaps In progress Planned
  1. F1 Done

    Identity & organization

    On-prem identity and one-directory foundation. Real AD verification remains.

  2. F2 Done

    Work foundation

    Tasks, My Work, notifications, recurring work and manual briefing.

  3. F3 Done

    Products & requests

    Catalog, request lifecycles, approvals and employee request UI.

  4. F4 Done

    Inventory & assets

    Procurement, stock, goods receipt and asset lifecycle.

  5. F5 Done

    Service desk & knowledge

    Tickets, knowledge, problems, runbooks and the internal side of the Autotask sync. The Autotask REST client and webhook remain.

  6. F6 Done

    Endpoint intelligence

    Devices, software, findings, assignment intelligence, history and diff. The live Microsoft Graph client remains.

  7. F7 Done

    Infrastructure & change

    Topology, services with impact analysis, changes with approvals and planning with a maintenance calendar.

  8. F8 Done

    Security & IT briefing

    Advisories, findings, remediation tracking and the computed IT briefing. Live advisory feeds remain.

  9. F9 Planned

    Software lifecycle

    Provider-based patch orchestration. IntuneGet → Intune is the intended path.

  10. F10 Planned

    Remote access

    Provider-based sessions with authorization and audit. HopToDesk, RustDesk and AnyDesk as first providers.

  11. F11 Planned

    Workforce presence

    Operational availability and team coverage, with privacy-scoped access.

  12. F12 Planned

    Turaco AI

    Typed tools acting as the requesting user. No AI runtime is implemented.
